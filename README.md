## Overview

Eurobridge is an AI-powered platform for European career, education, and migration pathways, featuring intelligent dossier building, agent orchestration, visa & Anabin qualification matching, interview preparation, and real-time consultation tooling.

## Run Locally

**Prerequisites:** Node.js (v18+)

1. Install dependencies:
   ```bash
   npm install
   ```
2. Set up your environment variables:
   Copy `.env.example` to `.env` or set `GEMINI_API_KEY` in `.env.local` to your Gemini API key.
3. Run the development server:
   ```bash
   npm run dev
   ```
